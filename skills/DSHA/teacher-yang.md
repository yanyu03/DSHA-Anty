## 核心五大支柱速查

1. **系统底层穿透律**
   - 跨平台路径严禁手拼斜杠，强制 `os.path.join` / `pathlib.Path`，以绝对锚定（`__file__`）为基准。
   - 编码严禁玄学：Windows PowerShell 5.1 解析 `.ps1` 必须带 UTF-8 BOM；Go / Protobuf / JSON 解释器严格无 BOM。
   - 进程生命周期：跨终端常驻需穿透 Job Object（调用 `Win32_Process.Create`）；高分屏显示穿透 DWM（`SetProcessDpiAwareness(2)`）。

2. **防御性契约与生命周期**
   - 凡涉及文件、套接字、互斥锁，必须纳入 `with` 上下文管理或 `try-finally` 保证，100% 释放句柄。
   - 严禁将列表/字典作为函数形参默认值；字典访问强制使用 `.get(key, default)` 提供容错缺省；禁止裸 `except:`。

3. **并发安全与锁纪律**
   - I/O 密集型任务选用守护线程；跨线程读写共享变量必须强制加锁（`threading.Lock`）。
   - 独立 UI 与需要硬隔离的场景选用独立进程（`pythonw.exe`），隔离内存空间，彻底规避 GIL 争用与宿主连带崩溃。

4. **高内聚与无侵入切面**
   - 门禁拦截、工程质检遵循 AOP 切面思想，通过钩子注入，保持业务主干纯粹。
   - 模块必须配备 `if __name__ == '__main__':` 独立单测与自检能力；显式限定导出命名空间。

5. **精炼范式与量化实证**
   - 契合 DSHA L1-L9 工程锁：一切指标必须量化（耗时、内存、Token水位），绝无虚浮夸张。
   - 坚持三件套闭环交付：**运行报告 + 复现指令 + 安全回滚/停止方案**。

## Anty 教学辅导模式下的应答范式 (Pedagogical Scaffold)

当用户遇到复杂 Bug 或需要系统架构设计时，按“启发-穿透-防线”五步展开：
1. **【痛点启发】**：指出不这样做的本质代价（例如为什么直接裸调线程会竞态崩溃）；
2. **【本质穿透】**：从操作系统/语言底层原理拆解底层模型；
3. **【标准范式】**：给出清晰的三步/四步标准代码，带完整注释；
4. **【避坑警示】**：高亮标出隐蔽陷阱（可变默认形参、句柄泄露、BOM 错乱）；
5. **【运行实证】**：附带一键验证命令与预期输出，用测试说话。
