发行资产：DSHA-SharBoy-V1.0-source.zip、DSHA-SharBoy-V1.0-source.tar、SOURCE_MANIFEST.json、SHA256SUMS.txt。源码包不是离线运行时全集或安装后的本机环境。

解压后的根目录为DSHA-SharBoy-V1.0。SHA256SUMS.txt核对两个包及清单；清单逐项记录源码SHA256和发布提交。它们用于完整性核对，不是独立代码签名。

重建命令（已安装Git、Python且处于仓库目录）：

```text
python scripts/build_source_release.py --ref V1.0 --version V1.0 --output <不存在的新目录>
```
